# Lesson01 Lab — Basic Prompting

This lab is the hands-on companion to [README.md](README.md). Read the README for the architecture and design rationale; use this file for the work you should perform yourself.

## Goal

Complete the smallest end-to-end AI request path so an HTTP prompt reaches Ollama through `IAiProvider` and returns generated text, model metadata, and duration.

## Predict

Before changing code, answer these questions:

1. Which layer should know about `OllamaApiClient`?
2. Which layer should know only about `IAiProvider`?
3. If the HTTP client disconnects, how can that cancellation reach an in-progress model call?
4. Which values in `AiResponse` are deterministic application metadata and which value is generated by the model?

## Run the Starter

```bash
dotnet run --project Lesson01.BasicPrompting
```

Then send:

```bash
curl -X POST \
  http://localhost:5000/api/prompt \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Explain dependency injection in two sentences."}'
```

The workshop starter intentionally leaves part of the request path incomplete. Observe the failure before fixing it.

## Build — Complete the AI Request Path

Complete the `Handler` / `IAiProvider` path so that:

- `Handler` delegates through `IAiProvider`;
- `OllamaProvider` sends the prompt to the configured Ollama model;
- streaming chunks are accumulated into one response;
- the response contains generated text, selected model, and elapsed duration;
- the supplied `CancellationToken` reaches the Ollama operation.

Do not move Ollama-specific SDK types into the feature layer.

## Run — Verify the Result

Verify `text`, `model`, and `duration`. Then run the same creative prompt several times and compare the responses:

```text
Give me three names for a software consulting company.
```

## Attack — Provider Failure

Stop Ollama and call the endpoint again. Observe that the ASP.NET application can remain alive while its external model dependency is unavailable.

## Attack — Prove Cancellation Reaches the AI Provider

Temporarily add this at the beginning of `OllamaProvider.SendAsync`:

```csharp
await Task.Delay(TimeSpan.FromSeconds(30), cancellationToken);
```

Start a request and press `Ctrl-C` in the `curl` terminal after a few seconds. The delay should be cancelled because request cancellation flowed through the endpoint, handler, interface, and provider.

Then remove the artificial delay and ask Ollama for an intentionally long response. Cancel while the model is generating. The same token is passed to `ChatAsync`, so this exercises cancellation during the real provider operation.

## Explain

1. Why is `IAiProvider` useful even with one provider?
2. Why does a cancellation token have to be passed to each cancellable operation?
3. Why is Ollama an external dependency even when it runs locally?
4. Why should tests assert the application contract rather than one exact generated paragraph?
